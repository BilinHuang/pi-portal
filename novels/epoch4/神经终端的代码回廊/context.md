## 一、 用户核心写作意见全谱系及深度动因 (Core Opinions & Rationales)

本节系统归纳用户在创作与审校全流程中所提出的全部核心指导意见，逐一剖析其背后的底层原因与美学逻辑。

### 1. 单章纯中文字数硬指标（$\ge 3000$ 字/章）
* **【用户意见】**：全书每一章节纯有效中文字数（统计 `[\u4e00-\u9fff]`）必须严格达到 3000 字以上。此前 1700～2100 字的章节全部判定为严重腰斩残篇，必须重构扩充。
* **【意见原因】**：
  * **长篇连载叙事节奏需要**：网络文学付费连载对单章厚度有固定预期，低于 3000 字无法支撑起完整的情节弧线与多层心理递进；
  * **微观感官与色气发酵需要足够篇幅**：支配、寸止、生理背叛与心理瓦解的过程是“慢工出细活”的微观物理雕刻。如果字数短，作者势必会快进跳过肉体受力、肌肉抽搐、神经电弧、体液渗透等微观感官描写，导致“起承转合过于仓促，调教还没发酵透就匆匆收尾”，丧失了顶级支配的沉浸感。
* **【满意的修改实战】**：
  * 对《深海国宴》原先严重腰斩的第 08～11 章进行全量大扩写：第 08 章扩至 **4528 字**，第 09 章扩至 **3201 字**，第 10 章扩至 **3072 字**，第 11 章扩至 **3016 字**；第 05～07 章亦通过充实物理受力细节全量补齐至 3000+ 字，全书 11 章实现 100% 达标。

### 2. 彻底清洗工科参数与医学教科书大词（感官日常化法则）
* **【用户意见】**：坚决清洗并杜绝在正文描写中堆砌任何仪表盘、机械工程物理量及临床解剖医学大词。黑名单包括：`牛顿`、`400兆帕`、`微秒`、`千帕`、`兆帕`、`赫兹`、`7赫兹`、`交感神经`、`副交感神经`、`去极化`、`动作电位`、`突触`、`闭锁`（生理阻断语境）等。
* **【意见原因】**：
  * **拒绝说明文出戏**：读者消费的是“高色气肉体溺毙与神经快感霸权”，追求的是肉体共情与被支配的窒息感，而不是在阅读潜艇机械维修手册或神经内科临床诊断报告；
  * **冰冷参数破坏性张力**：生硬的数字与学术词汇具有天然的“疏离感”，会瞬间把读者从滚烫黏腻的生理共情中拉扯出来，严重破坏行文的文学张力与审美沉浸。
* **【满意的修改实战】**：
  * 建立精准的文学化日常转译体系：
    * 将“XX牛顿拉力”转译为“将肌腱与关节撕扯到近乎极限的恐怖坠力”、“失去一切支撑后的绝望沉重下坠”；
    * 将“交感神经过载区 / 去极化阻断”转译为“深入骨髓的麻痒”、“自尾椎炸开的剧烈触电感”、“深层神经死穴”；
    * 将“7赫兹超低频”转译为“巨鲸深沉脉动般的超低频低鸣”；
    * 将“闭锁咬合”转译为“刚性咬合死锁”；
    * 全面扫清了全书三部作品的所有生硬词汇。

### 3. 严禁独立成段拟声词（拟声词融解叙事规范）
* **【用户意见】**：严禁出现任何独立成段的拟声词与短叹号行（如单独成行的 `“轰——！！”`、`“啪！”`、`“嗒。”`、`“咔哒。”`、`“呜呜呜……”` 等）。
* **【意见原因】**：
  * **摒弃轻小说/漫画式的廉价偷懒分镜**：独立拟声词成段是日式轻小说或视觉漫画的偷懒排版手段，在严肃长篇文学叙事中会严重割裂文本的气息与节奏；
  * **避免注水嫌疑，保持文字厚重感**：拟声词独立成行会稀释段落信息密度。真正高级的音效，应当作为环境背景音或生理反应的一部分，有机融入主谓宾完整的长句叙事中。
* **【满意的修改实战】**：
  * 将《深海国宴》各章原有的数十处独立拟声词全部融解进长句，例如：
    * 原文独立的 `“轰——！！”` 改写为：“伴随着骨盆深处的沉闷轰鸣，两股截然相反的力道合流爆发，薇拉眼前的世界几乎彻底融化成一片混沌的白昼”；
    * 原文独立的 `“嗒。”` 改写为：“右脚军靴踏落在大理石地面上，鞋跟传感器闭合，同步引爆微波脉冲”。

## 三、 指南架构拆分的意见、动因与最终形态 (Guideline Modular System)

### 1. 用户的困扰与核心意见
* **困扰原话**：“现在的 guideline 需要拆分成两个模块，一个叫 prompt，一个叫 checklist，写的 agent 只能看到 prompt，检查的依据 checklist 检查。如果给了完整 guideline 会框太死，不给又太自由，怎么办？”
* **核心动因深度解构**：
  * **单体指南的注意力污染**：旧版将所有规则（正面写法 + 负面审查禁令）混杂在一起，写作模型背负过多负向包袱，导致文字过度防守、干瘪拘谨；
  * **“框架过载”与“风格串味”**：旧版将古典宫廷、重工科技、柔性触手、攻守易势及 6 种终局一股脑喂给模型，模型要么觉得规则太多被框死，要么在写现代潜艇时串出触手或皮具，消化不良；而一旦完全删掉（如后来的特化版），又丢失了其他题材的宝贵资产。

### 2. 最终确立的工业化三层解耦方案（满意形态）
保留原有历史文件（`guideline.md`、`guideline_new.md`）不删，重构为全新三层架构：

```text
guideline/
├── context.md                            # 【全量上下文】本备忘录（秒级全盘对齐）
├── README.md                             # 【架构说明】多 Agent 标准调用流水线
├── prompt_core.md                        # 【生成端必读】写作 Agent 专用引擎（无负向污染、充沛情绪燃料）
├── checklist.md                          # 【审核端必读】质检 Agent 专用卡尺（字数/四大项/禁词/非黑即白）
│
└── reference_modules/                    # 【剧情素材库】立项策划按需拼装菜单（按需调取，拒绝全喂）
    ├── 01_restraint_matrix.md            # 材质矩阵：重工科技 / 原教旨古典 / 柔性触手与纳米
    ├── 02_plot_paradigms.md              # 叙事范式：三大经典推进范式 + 喉间截断/走钢丝特色模型
    ├── 03_reversal_module.md             # 核心反转：攻守易势 · 绝对清算与身份彻底对调
    └── 04_ending_archetypes.md           # 多元终局：六大终局库（含昏迷自主反射高潮深度版）
```

### 3. 多 Agent 协同运转黄金法则
1. **策划阶段**：从 `reference_modules/` 中点菜（1 材质 + 1 范式 + 1 终局），实例化进《分章细纲》；
2. **写作阶段**：写作 Agent 上下文**仅加载 `prompt_core.md` + 本章细纲**，杜绝多余设定干扰；
3. **质检阶段**：审核 Agent **严格对照 `checklist.md`** 机械式扫描，不合格直接出具带行号修改清单；
4. **修复阶段**：写作 Agent 依据审查行号定向重构。
