# 项目文件与交付物命名统一规范 (File Naming Convention)

> **归档位置**：`naming_convention.md`（与分卷编译脚本 `merge_volumes.py` 同级存放）  
> **制定目的**：统一项目在创意构思、分章细纲、正文生成、分卷编译与最终交付全生命周期中的文件命名规则，确保多 Agent 协作检索无歧义，并保障自动化脚本（如编译合并、字数审计）的高效运行。

---

## 一、 核心命名规范全览表 (Core Naming Matrix)

| 类别 / 资产类型 | 统一命名语法 (Pattern) | 实际示例 | 存储目录 | 编码与格式 |
| :--- | :--- | :--- | :--- | :--- |
| **总大纲** | `outline.md` | `outline.md` | 项目根目录 | Markdown / UTF-8 |
| **单章细纲** | `outline_{三位序号}_{章节名}.md` | `outline_001_生化培养皿的活性死锁.md` | 项目根目录 | Markdown / UTF-8 |
| **章节正文** | `{三位序号}_{章节名}.txt` | `001_生化培养皿的活性死锁.txt` | 项目根目录 | 纯文本 TXT / UTF-8 |
| **Release 分卷交付** | `{两位序号}_{卷名}({起始章}-{结束章}).txt` | `01_上卷_活性死锁与奉献展台(1-3).txt` | `release/` 目录 | 纯文本 TXT / UTF-8 |
| **全本合集 (可选)** | `{书名}_全本合并.txt` | `生化温床的共犯触须_全本合并.txt` | 项目根目录 | 纯文本 TXT / UTF-8 |

## 二、 各类文件命名标准与格式约束

### 1. 总大纲 (`outline.md`)
- **命名语法**：固定为 `outline.md`（全小写，杜绝 `chapter_outlines.md`、`outline_all.md` 等别名）。
- **定位与作用**：承载全书的世界观设定、核心机制、角色四阶心智降级梯度、全 11 章章节规划与正戏篇幅分配。
- **排版要求**：标准 Markdown 格式，层级分明，作为全书立项与各分章细纲拆解的唯一总纲底座。

---

### 2. 单章细纲 (`outline_{三位序号}_{章节名}.md`)
- **命名语法**：`outline_{三位序号}_{章节名}.md`
  - **前缀**：固定为小写 `outline_`；
  - **三位序号**：`001` 至 `011`（严格按 3 位纯数字补零，严禁出现 `1`、`01`、`第01章` 等非标格式）；
  - **分隔符**：单下划线 `_`；
  - **章节名**：使用精准中文章节名称，杜绝空格与特殊符号。
- **命名示例**：
  - `outline_001_生化培养皿的活性死锁.md`
  - `outline_002_主宰临场与奉献性腾退.md`
  - `outline_003_活体奉献展台的外展托举.md`
- **内容约束**：必须明确包含 4 段式分场推进（每场规划字数）、四大必载调控元素落地细节、痛欲转化机制与身心背叛反应。

---

### 3. 章节正文 (`{三位序号}_{章节名}.txt`)
- **命名语法**：`{三位序号}_{章节名}.txt`
  - **三位序号**：`001` 至 `011`（严格按 3 位纯数字补零开头）；
  - **分隔符**：单下划线 `_`；
  - **章节名**：与细纲章节名称保持 100% 逐字严格一致；
  - **扩展名**：必须为纯文本 `.txt`。
- **命名禁忌**：
  - ❌ **严禁**：`第01章_生化培养皿的活性死锁.txt`（不要前缀“第”和“章”）；
  - ❌ **严禁**：`01_生化培养皿的活性死锁.txt`（不可使用 2 位数字）；
  - ❌ **严禁**：`001 生化培养皿的活性死锁.txt`（不可使用空格替代下划线）；
  - ❌ **严禁**：`001_生化培养皿的活性死锁.md`（正文严禁用 Markdown）。
- **命名示例**：
  - `001_生化培养皿的活性死锁.txt`
  - `002_主宰临场与奉献性腾退.txt`
  - `003_活体奉献展台的外展托举.txt`
  - `004_多线程夹击的盲区折磨.txt`
  - `005_既定败局——抗拒共生的限时考核.txt`
  - `006_共生催情黏液的黏膜渗透.txt`
  - `007_体内常驻拟态核心的寄生.txt`
  - `008_多向沦陷的肉体背叛感.txt`
  - `009_触手与主宰的合谋绝顶风暴.txt`
  - `010_共生契约下的神智皈依.txt`
  - `011_生化温床的永恒共犯.txt`

---

### 4. Release 分卷交付文件 (`{两位序号}_{卷名}({起始章}-{结束章}).txt`)
- **命名语法**：`{两位序号}_{卷名}({起始章}-{结束章}).txt`
  - **两位序号**：`01`、`02`、`03`（2 位数字补零）；
  - **卷名**：清晰表达该分卷在剧情弧线中的定位（如 `上卷_活性死锁与奉献展台`）；
  - **章节范围**：紧跟英文半角括号 `({起始章}-{结束章})`，数字不补零（如 `(1-3)`、`(4-7)`、`(8-11)`）；
  - **扩展名**：纯文本 `.txt`。
- **命名示例**：
  - `01_上卷_活性死锁与奉献展台(1-3).txt`
  - `02_中卷_多轴夹击与拟态寄生(4-7).txt`
  - `03_下卷_绝顶风暴与永恒共犯(8-11).txt`
- **卷内文本排版铁律**：
  1. 卷内每一章节开头必须且只能使用标准章节标签：`[chapter:章节名称]`（严禁添加外部横线或装饰框）；
  2. 章节之间**严禁**插入 `[newpage]` 或任何伪分页标记；
  3. 各章正文内容 100% 保持与单章正文原样一致，杜绝任何二次增删。

## 三、 正则匹配与自动化脚本适配规范 (Regex & Script Integration)

自动化处理脚本（如 Python 编译合并器 `merge_volumes.py`、批量重命名工具或字数审计脚本）应统一使用以下正则表达式进行文件解析：

```python
import re

# 1. 章节正文匹配模式: 提取序号与章节名
CHAPTER_TXT_PATTERN = re.compile(r'^(\d{3})_(.+)\.txt$')
# 匹配示例: "001_生化培养皿的活性死锁.txt" -> group(1)="001", group(2)="生化培养皿的活性死锁"

# 2. 单章细纲匹配模式: 提取序号与章节名
OUTLINE_MD_PATTERN = re.compile(r'^outline_(\d{3})_(.+)\.md$')
# 匹配示例: "outline_001_生化培养皿的活性死锁.md" -> group(1)="001", group(2)="生化培养皿的活性死锁"

# 3. Release 分卷文件匹配模式: 提取卷序号、卷名、起止章节
RELEASE_VOL_PATTERN = re.compile(r'^(\d{2})_(.+)\((\d+)-(\d+)\)\.txt$')
# 匹配示例: "01_上卷_活性死锁与奉献展台(1-3).txt" -> vol="01", name="上卷_...", start=1, end=3
```
